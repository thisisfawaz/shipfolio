# Shipfolio

> The portfolio built for people who ship products.

## What is Shipfolio?

Shipfolio is a portfolio platform designed specifically for product builders, founders, indie hackers, developers, and makers who constantly ship products.

Instead of spending hours updating a portfolio every time a new project is finished, you simply archive each project in Shipfolio. Over time, your public profile automatically becomes a living portfolio that showcases not only what you built, but also how you think.

## Features

- ✅ **Dynamic Sections** — Add unlimited custom sections to every product
- ✅ **Build Medals** — Automatically awarded as you ship more products
- ✅ **Product Stats** — Total products, categories, average build time
- ✅ **Private Notes** — Keep internal notes visible only to you
- ✅ **Clean Design** — Minimal, typography-focused, responsive
- ✅ **Supabase + Next.js** — Full-stack with authentication and storage

## Quick Start

```bash
# Install dependencies
npm install

# Set up environment variables
cp .env.local .env
# Edit .env with your Supabase credentials

# Run the development server
npm run dev
```

## Database Setup

1. Create a Supabase project
2. Run the SQL schema from `supabase-schema.sql` in the SQL Editor
3. Enable authentication (email/password)

## Deployment

Deploy to Vercel:

1. Push to GitHub
2. Import project on Vercel
3. Add environment variables
4. Deploy!
